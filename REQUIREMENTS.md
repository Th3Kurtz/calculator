# requirements
1) must be able to add two numbers
2) must be able to subtract two numbers
3) must be able to multiply two numbers
4) must be able to divide two numbers
5) must be able to display a result
6) must be able to take an input of some kind
7) must be able to be used from the Terminal

example input/expected results:
10/0 = undefined
16/2 = 8
4 + 10 = 14
15-20 = -5
